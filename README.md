# The Solar Co — Sun Studio

An original responsive solar website concept with a light slate-and-orange palette, frosted navigation and a custom interactive architectural home.

## Local preview

With Node.js 20 or newer installed, run `npm start` and open http://127.0.0.1:4173. There are no packages to install. Use `npm run check` for JavaScript syntax checks.

## GitHub Pages

The repository root contains the complete static website. In repository Settings → Pages, choose **Deploy from a branch**, select **main**, and select **/(root)**. No build step is needed. All resources use relative paths and are bundled locally.

## Preview status

The enquiry form validates inputs and displays a demonstration confirmation. It does not send or save visitor details. A real backend and approved privacy information are required before collecting enquiries.

The architectural model is an original illustration, not an installed project or a performance forecast. Approved Solar Co company details, service scope and genuine testimonials remain content requirements. Lightforce material has not been represented as Solar Co business facts.
